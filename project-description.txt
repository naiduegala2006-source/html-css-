This personal portfolio website for Egala Naidu is engineered using semantic HTML5 and modern pure CSS3 to showcase software development and AI/ML engineering capabilities. Built strictly without JavaScript, frameworks, or external assets, the site leverages native CSS perspective and 3D transforms to create an interactive, high-tech experience with an animated 3D hero core and depth-layered cards. The interface features a dark technical palette with high-contrast electric cyan accents, structured skill categories, and detailed project breakdowns including the FundGuard transaction monitoring system with its simulated test benchmarks. Full accessibility is integrated throughout, including WCAG AAA color contrast, visible keyboard focus indicators, landmark navigation with skip links, and comprehensive prefers-reduced-motion adaptation.
